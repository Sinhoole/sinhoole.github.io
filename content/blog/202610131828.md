# OverplayHUD

## V2.3.0

本次更新为右下角子弹装饰带加入动态效果，并修复了部分系统下动画整体失效的问题。

**新增 · 子弹装饰带动效**

- **射击滚动**：射击时整条子弹带右移一格，右端一颗滑出、左端一颗补入；弹药充足时显示数量恒定，连续扫射逐格推进。一帧内多发齐落时合并为一次连续快滚，避免动画积压滞后。
- **低弹量转红**：弹匣数降至阈值以下时，整条子弹带转为红色（与弹匣数字转红同一逻辑）；弹药不多时射击只掉出不补充，左端随之空出。
- **滚动模糊**：滚动过程中为整条子弹带叠加运动模糊，连续射击时模糊持续存在，停下即恢复清晰；强度可在设置中调节，设为 0 即关闭。

**修复 · 系统「动画效果」关闭导致动效失效**
部分系统将「动画效果」关闭后，HUD 的滚动、模糊与击杀徽章动画会被整体禁用（弹匣计数不受影响）。新增「忽略系统减少动态」开关，开启后动画照常播放。

**设置项**
「弹药 / 连杀」页新增：子弹颜色、低弹量颜色、低弹量阈值、射击滚动动画、滚动时长、滚动模糊、忽略系统减少动态。

## V2.2.0

1.新增武器栏 SVG 态，以纯色剪影显示 1–5 号武器，图标右对齐、编号成一列，可单独设置每个槽位的辉光色选中时高亮放大并显示武器名，投掷物只标注手上那颗；名称的位置、颜色、字号、辉光均可调，剪影支持默认色与逐槽位独立配色；5 号槽位按阵营显示 C4 或拆弹器。

2.新增更新公告页，自动比对本地与公告版本，提示「存在可更新内容 / 已更新至最新版本 / 已更新至预览版本」。
