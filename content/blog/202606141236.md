# 教程



## 简介

这是一套适用于 **CS2 ** 的聊天 CFG 脚本。按下 **右 Alt 键** 一键启动，之后每按一次 **M 键** 即可在公屏自动发送一条预设文本，共 **166 条**，按完自动循环。

> 无需切换模式、无需记组合键，一个键启动，一个键发送。

## 功能速览

| 操作        | 效果                           |
| ----------- | ------------------------------ |
| 按 `右 Alt` | 启动轮盘，HUD 变为橙色         |
| 按 `M`      | 发送当前文本，自动切换到下一条 |
| 持续按 `M`  | 逐条发送，166 条后回到第一条   |

## 安装步骤

### 4.自定义配置

#### 1.颜色

| 数字 | 颜色         |
| ---- | ------------ |
| 0    | 默认（白色） |
| 1    | 白色         |
| 2    | 红色         |
| 3    | 绿色         |
| 4    | 淡蓝         |
| 5    | 淡绿         |

| 7    | **橙色**     |
| 8    | 紫色         |
| 9    | 灰色         |
| 10   | **蓝色**     |
| 11   | **粉色**     |

#### 2.修改按键

将源代码中的 `bind m msg001` 中的 `m` 改为你想要的键位，例如改为 `n`：

```cfg
alias "chat" "cl_hud_color 7; bind n msg001"
```

同时需要把文件中所有的 `bind m` 替换为 `bind n`（共 166 处，可用文本编辑器的「全部替换」功能）。

#### 3.修改启动按键

将最后一行的 `bind "ralt" "chat"` 中的 `ralt` 改为其他键位，例如改为 `f1`：

```cfg
bind "f1" "chat"
```

#### 4.增删文本

每条文本的格式如下：

```cfg
alias "msg001" "say 你的文本内容;bind m msg002"
```

- `msg001`：本条编号
- `say` 后的内容：发送的文本
- `bind m msg002`：按下 M 后跳转到下一条

**添加新条**：在末尾的 `msg166` 后新增 `msg167`，并修改 `msg166` 的跳转目标指向 `msg167`，`msg167` 的跳转目标指向 `msg001` 形成闭环。

**删除某条**：将上一条的跳转目标改为指向下一条即可跳过。

## 技术原理

脚本利用了 Source 引擎的 `alias` 和 `bind` 指令：

1. **alias** 定义了一个「别名」，别名中可以包含多条指令，用分号 `;` 分隔
2. **bind** 将按键绑定到某个指令或别名
3. 每条 `msg###` 别名的内容做了两件事：
   - `say <文本>` — 在公屏发送消息
   - `bind m msg###` — 将 M 键重新绑定到下一条消息

这样就形成了一个**动态重绑定的链式结构**：每按一次 M，发送当前文本，然后自动把 M 指向下一条，以此类推直到末尾再回到第一条。

```
按 RAlt → 激活 chat → HUD变色 + 绑定 M 到 msg001
按 M → 发送 msg001 文本 → M 自动指向 msg002
按 M → 发送 msg002 文本 → M 自动指向 msg003
...
按 M → 发送 msg166 文本 → M 自动指向 msg001（循环）
```

## 常见问题

**Q: 按 M 没反应？**

A: 先按右 Alt 启动。如果还不行，检查是否已执行 `exec chat.cfg`，或者是否在正确的文件夹。

**Q: 换图后失效了？**

A: 重置绑定即可。

**Q: 会触发 VAC 吗？**

A: 不会。这些都是 Source 引擎自带的合法控制台指令，不属于外挂范畴。但发送的内容可能在平台服务器被禁言。
