# 欢迎使用 Hexo！

这是你的第一篇文章。你可以通过修改 `source/_posts/hello-world.md` 来编辑它。

## 快速开始

### 创建一篇新文章

```bash
hexo new "My New Post"
```

更多信息请查看 [Writing](https://hexo.io/docs/writing.html)。

### 运行服务器

```bash
hexo server
```

更多信息请查看 [Server](https://hexo.io/docs/server.html)。

### 生成静态文件

```bash
hexo generate
```

更多信息请查看 [Generating](https://hexo.io/docs/generating.html)。

### 部署到远程站点

```bash
hexo deploy
```

更多信息请查看 [Deployment](https://hexo.io/docs/one-command-deployment.html)。
