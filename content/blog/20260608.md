# 优雅地使用Codex

## 安装Codex

对于ClaudeCode来说，无疑Codex现在如日中天，非常简便的操作方式、非常完善的汉化、非常简洁的页面。对比于C来deCode来说必然是一个更好的选择。

Codex的下载链接直接在Bing上搜索就可以找到，有更为简单的方法就是在MicrosoftStore中搜索下载。

MicrosoftStoreLink Codex -> [Codex Download](https://apps.microsoft.com/detail/9plm9xgg6vks) <-

点击下载连接以后会跳转到Codex的下载界面，点击下载后，浏览器的右上角会弹出CodexInstaller.exe文件，点击运行即可。

![下载页面](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608160255300.png)

![image-20260608160410756](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608160410756.png)

安装Codex很简单，但是Codex的使用并没有想象中的那么方便。受制于众所周知的原因，Codex并不为中国大陆地区用户提供网络服务，即使使用了代理软件，也会遇到比较难解决的电话号验证问题。![image-20260608160631473](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608160631473.png)

对于此问题，本文章提供两种解决办法。

- 使用SMS接码平台进行注册。
- 使用Codex++跳过注册。

本文章将对第二种方法进行详细的讲解。

## 安装Codex ++

Codex++ 是面向 Codex App 的外部增强启动器和管理工具。它不修改 Codex App 原始安装文件，而是通过外部 launcher 启动 Codex，并使用 Chromium DevTools Protocol 注入增强脚本。

Codex++ Release Page -> [Codex++Release]([Releases · BigPizzaV3/CodexPlusPlus](https://github.com/BigPizzaV3/CodexPlusPlus/releases)) <-

点击适用于Windows平台的`CodexPlusPlus-1.2.4-windows-x64-setup.exe`进行下载安装

![image-20260608161313464](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608161313464.png)



## CC Switch

CC Switch 是一款跨平台桌面应用，专为使用 AI 编程工具的开发者设计。它帮助你统一管理 **Claude Code**、**Claude Desktop**、**Codex**、**Gemini CLI**、**OpenCode**、**OpenClaw** 和 **Hermes** 等受管应用的配置。

同样的，点击CC Switch的官方Release页面进行下载。 -> [Releases · farion1231/cc-switch](https://github.com/farion1231/cc-switch/releases) <-

![image-20260608161810399](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608161810399.png)



## 开始操作

### 开启路由

点击“设置”。

进入“路由”。

打开“本地路由总开关”。

勾选正在使用的客户端Codex。

![image-20260608162035010](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608162035010.png)

### 配置Api Key

点击主页右上角的加号，输入你在Deepseek配置的API Key,形如`sk-a8a8a8a8a8a8a8a8a8a8a8a8a8a8a8a8a`

![image-20260608165059928](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608165059928.png)

配置完成后点击启用按钮，如图所示。

![image-20260608162834191](https://cdn.jsdelivr.net/gh/UieTego/Po1@main/image-20260608162834191.png)

### 启动Codex++

启动桌面的Codex++，选择其他方式登录，并且填入sk-1作为虚假的ApiKey，然后登陆。

Congratulations！你已经进入Codex了。
