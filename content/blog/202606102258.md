# 第1章 基本概念及定义

---

## 1.1 工质和热力系统

### 核心概念对比表

| 系统类型     | 定义                           | 特点                           | 举例             |
| :----------- | :----------------------------- | :----------------------------- | :--------------- |
| **闭口系统** | 与外界无物质交换               | 控制质量（CM），系统内质量恒定 | 气缸中的气体     |
| **开口系统** | 与外界有物质交换               | 控制体积（CV），有工质流进流出 | 汽轮机、压气机   |
| **绝热系统** | 与外界无热量交换               | Q=0，但可以有功的交换          | 绝热良好的容器   |
| **孤立系统** | 与外界既无物质交换也无能量交换 | 完全隔离，ΔU=0，ΔS≥0           | 宇宙（理论上的） |

> ⚠️ **考试易错**：孤立系统 ⊂ 绝热系统 ⊂ 闭口系统。孤立系统要求**既无物质交换也无能量交换**，比绝热系统更严格。

### 补充概念

- **不可压缩流体**：比体积不变的流体，通常液体可近似为不可压缩
- **简单可压缩系统**：只有一种可逆功模式（体积变化功）的系统，状态只需两个独立参数确定

---

## 1.2 状态参数

### 状态参数的核心特性

> **状态参数只与初终态有关，与路径无关！**

| 参数     | 符号 | 单位  | 类型   | 备注                              |
| :------- | :--- | :---- | :----- | :-------------------------------- |
| 温度     | T    | K     | 强度量 | 热力学温标，T(K) = t(°C) + 273.15 |
| 压力     | p    | Pa    | 强度量 | 1 bar = 10⁵ Pa, 1 atm = 101325 Pa |
| 比体积   | v    | m³/kg | 强度量 | v = V/m                           |
| 密度     | ρ    | kg/m³ | 强度量 | ρ = 1/v                           |
| 热力学能 | U    | J     | 广延量 | 也叫内能                          |
| 焓       | H    | J     | 广延量 | H = U + pV                        |
| 熵       | S    | J/K   | 广延量 | dS = δQ_rev/T                     |

### 强度量 vs 广延量

|            | 强度量            | 广延量                                         |
| :--------- | :---------------- | :--------------------------------------------- |
| **定义**   | 与系统质量无关    | 与系统质量成正比                               |
| **可加性** | 不可加            | 可加                                           |
| **举例**   | p, T, v（比体积） | V, U, H, S                                     |
| **比参数** | 本就是强度量      | 除以质量后变为强度量（如 u=U/m, h=H/m, s=S/m） |

### 热力学第零定律（热平衡定律）

> 如果系统A与系统B热平衡，系统B与系统C热平衡，则系统A与系统C也热平衡。
>
> **结论**：互为热平衡的物体具有**相同的温度**（这是温度可以测量的理论基础）。

### 压力换算（必记！）

$$p_{abs} = p_{atm} + p_g \quad \text{（表压力为正时）}$$

$$p_{abs} = p_{atm} - p_v \quad \text{（真空度为正时）}$$

- $p_{abs}$ — 绝对压力；$p_g$ — 表压力（gauge）；$p_v$ — 真空度
- **表压力不是状态参数**（因为它依赖于当地大气压）
- 热力计算中必须使用**绝对压力**！

| 常用换算                     |                   |
| :--------------------------- | :---------------- |
| 1 atm = 101325 Pa = 760 mmHg | 1 bar = 10⁵ Pa    |
| 1 MPa = 10⁶ Pa = 10 bar      | 1 mmH₂O = 9.81 Pa |
| 1 mmHg = 133.3 Pa            |                   |

## 1.3 平衡状态

### 平衡状态 vs 稳定状态 vs 均匀状态

|                      | 平衡状态                               | 稳定状态                                 | 均匀状态           |
| :------------------- | :------------------------------------- | :--------------------------------------- | :----------------- |
| **定义**             | 无外界影响下，系统宏观性质不随时间变化 | 系统参数不随时间变化（可有外界作用维持） | 系统内各点参数相同 |
| **条件**             | 热平衡 + 力平衡 + 化学平衡             | 只需参数不随时间变                       | 各处一致           |
| **可否在坐标图表示** | ✅ 可以                                 | ❌ 不一定                                 | ❌ 不一定           |

> ⚠️ **平衡状态一定稳定，但稳定不一定是平衡！**
> 例如：稳态导热时，棒两端有恒温差，温度分布稳定但不是平衡态。

### 状态公理

> 确定简单可压缩系统的状态，只需要**两个独立的状态参数**。

---

## 1.4 热力过程

### 准静态过程 vs 可逆过程

|                | 准静态过程                                 | 可逆过程                                  |
| :------------- | :----------------------------------------- | :---------------------------------------- |
| **定义**       | 过程进行得无限缓慢，系统始终无限接近平衡态 | 过程完成后，系统和外界都能完全复原        |
| **充要条件**   | 内部可逆（无内部耗散）即可                 | 内部可逆 + 外部可逆（无温差传热、无摩擦） |
| **在坐标图上** | 可用实线表示                               | 可用实线表示                              |
| **包含关系**   | 可逆过程一定是准静态过程                   | 准静态不一定是可逆过程                    |

> **核心记忆**：可逆过程 = 准静态过程 + 无耗散效应（无摩擦、无温差传热）

### 不可逆过程举例

- 摩擦（机械能→内能）
- 有限温差传热
- 自由膨胀
- 混合过程
- 电阻发热

---

## 1.5 功和热量

### 本质区别

|                  | 功 (W)                 | 热量 (Q)           |
| :--------------- | :--------------------- | :----------------- |
| **定义**         | 通过宏观位移传递的能量 | 通过温差传递的能量 |
| **是状态参数吗** | ❌ 不是，是过程量       | ❌ 不是，是过程量   |
| **符号约定**     | 系统对外做功为+        | 系统吸热为+        |
| **微分符号**     | δW（非全微分）         | δQ（非全微分）     |

### 体积变化功（膨胀功/压缩功）

$$\delta W = p \cdot dV \quad \text{（可逆过程）}$$

$$W_{12} = \int_{V_1}^{V_2} p \, dV$$

> **P-V图面积 = 膨胀功**：P-V图上过程曲线与V轴围成的面积。
>
> **T-S图面积 = 热量**：T-S图上过程曲线与S轴围成的面积。

### 过程吸热还是放热？

判断依据：**T-S图上过程方向** — 熵增大为吸热，熵减小为放热。

---

## 1.6 热力循环

### 正循环（动力循环）：热→功

**热效率**：

$$\eta_t = \frac{W_{net}}{Q_1} = 1 - \frac{Q_2}{Q_1}$$

- $Q_1$：从高温热源吸收的热量
- $Q_2$：向低温热源放出的热量
- $W_{net} = Q_1 - Q_2$

### 逆循环（制冷/热泵循环）：耗功→从低温吸热

|              | 制冷循环                                     | 热泵循环                                      |
| :----------- | :------------------------------------------- | :-------------------------------------------- |
| **目的**     | 从低温处吸热（制冷）                         | 向高温处放热（供暖）                          |
| **性能指标** | 制冷系数 $\varepsilon = \frac{Q_2}{W_{net}}$ | 热泵系数 $\varepsilon' = \frac{Q_1}{W_{net}}$ |
| **关系**     | $\varepsilon' = \varepsilon + 1$             |                                               |

> ⚠️ 两者的设备相同、原理相同，区别只在于**使用的目的不同**！

# 第2章 热力学第一定律

---

## 2.1 热力学第一定律的实质

> **能量守恒与转换定律在热现象中的应用。**
>
> **核心表述**：热可以变为功，功也可以变为热；一定量的热消失时，必产生与之数量相当的功；消耗一定量的功时，也必出现相应数量的热。

$$\oint \delta Q = \oint \delta W$$

也就是说，**第一类永动机（不消耗能量而不断做功的机器）是造不出来的**。

---

## 2.2 热力学能（内能）

### 关键结论

> ⚡ **热力学能 U 是状态参数！**（与路径无关）

- 热力学能包含：分子动能 + 分子势能 + 化学能 + 核能等
- 工程热力学中通常只考虑分子动能和分子势能的变化
- 对理想气体，热力学能**只与温度有关**（焦耳定律，第3章详述）

$$\Delta U = U_2 - U_1$$

---

## 2.3 闭口系能量方程

### 核心公式（必背！）

$$Q = \Delta U + W$$

- **物理意义**：系统吸收的热量 = 热力学能增量 + 系统对外做功
- **微分形式**：$\delta Q = dU + \delta W$
- **对于可逆过程**：$\delta Q = dU + p \, dV$

### 几种特殊情况

| 过程类型        | 简化形式            | 说明                 |
| :-------------- | :------------------ | :------------------- |
| 绝热过程 (Q=0)  | $W = -\Delta U$     | 做功完全来自内能减少 |
| 等容过程 (W=0)  | $Q = \Delta U$      | 吸热全部转化为内能   |
| 循环过程 (ΔU=0) | $Q_{net} = W_{net}$ | 净吸热 = 净做功      |

---

## 2.4 流动功和焓

### 流动功

> 开口系统中，工质流入流出系统时需要克服压力所做的功。

$$W_f = pV = p \cdot m \cdot v$$

- 流动功是**开口系统**特有的概念（闭口系统没有）
- 流动功 = 压力 × 体积

### 焓（重要！第2-8章反复出现）

$$\boxed{H = U + pV}$$

**比焓**：$h = u + pv$

> ⚠️ **焓是状态参数！**（因为 U、p、V 都是状态参数）

**常见误解纠正**：
- 焓在**任何**过程中都有定义（不只是等压过程）
- 焓的定义式 $h = u + pv$ 永远成立
- 但只有在**稳定流动等压过程**中，吸热量才等于焓变（$\delta Q = dh$）

### 焓在不同过程中的含义

| 过程             | Q与Δh的关系                  | 说明                                        |
| :--------------- | :--------------------------- | :------------------------------------------ |
| 闭口等压过程     | $Q = \Delta H$               | 等压吸热=焓增（此时代入闭口系能量方程可证） |
| 稳定流动         | $\delta q = dh + \delta w_t$ | 能量方程的通式                              |
| 绝热节流         | $h_1 = h_2$                  | 节流前后焓相等（等焓过程）                  |
| 理想气体任意过程 | $\Delta h = c_p \Delta T$    | 焓变仅取决于温度变化                        |

---

## 2.5 稳定流动能量方程及其应用

### 稳定流动的定义

> 系统内各点的状态参数**不随时间变化**。

特点：
1. 进出口工质质量流量相等
2. 系统内各点参数（p, T, v, c等）不随时间变化
3. 系统与外界交换的热量和功不随时间变化

### 稳定流动能量方程（核心公式！）

$$\boxed{q = \Delta h + \frac{1}{2}\Delta c^2 + g\Delta z + w_i}$$

- $q$：单位质量工质吸热量
- $\Delta h$：焓变
- $\frac{1}{2}\Delta c^2$：动能变化
- $g\Delta z$：位能变化
- $w_i$：内部功（工质对机器做的功）

### 技术功

$$\boxed{w_t = w_i + \frac{1}{2}\Delta c^2 + g\Delta z}$$

$$w_t = -\int_{p_1}^{p_2} v \, dp \quad \text{（可逆过程）}$$

- 技术功 = 工程上可利用的功
- **等压过程技术功为零**（dp=0）

### 技术功与膨胀功的关系

$$w_t = w - \Delta(pv) = w - (p_2v_2 - p_1v_1)$$

### 各种热力设备（考试高频！）

| 设备            | 简化条件               | 能量方程简化                             | 核心结论                |
| :-------------- | :--------------------- | :--------------------------------------- | :---------------------- |
| **汽轮机**      | q≈0, Δc≈0, Δz≈0        | $w_i = -\Delta h = h_1 - h_2$            | 输出功 = 焓降           |
| **压气机**      | q≈0, Δc≈0, Δz≈0        | $-w_i = \Delta h = h_2 - h_1$            | 耗功 = 焓增             |
| **锅炉/换热器** | w_i=0, Δc≈0, Δz≈0      | $q = \Delta h$                           | 吸热 = 焓增             |
| **喷管**        | q=0, w_i=0, Δz≈0       | $\frac{1}{2}(c_2^2 - c_1^2) = h_1 - h_2$ | 动能增加 = 焓降         |
| **节流阀**      | q=0, w_i=0, Δc≈0, Δz≈0 | $h_1 = h_2$                              | **绝热节流 = 等焓过程** |

> ⚠️ **强烈建议背下这张表**，考试中绝大多数开口系问题都能归入这五类！

### 绝热节流

- **特点**：$h_1 = h_2$（前后焓相等）
- 但节流是**不可逆过程**，熵增加
- 在坐标图上：绝热节流画成**虚线**（因为是不可逆过程，中间状态非平衡）
- 对理想气体：节流前后温度不变（$T_1 = T_2$）
- 对实际气体：节流后温度可能升高、降低或不变（焦耳-汤姆逊效应）

## 📊 第1-2章横向对比总结

| 对比项       | 闭口系统                              | 开口系统（稳定流动）                                     |
| :----------- | :------------------------------------ | :------------------------------------------------------- |
| 能量方程     | $Q = \Delta U + W$                    | $q = \Delta h + \frac{1}{2}\Delta c^2 + g\Delta z + w_i$ |
| 可逆功表达式 | $W = \int p\,dV$                      | $w_t = -\int v\,dp$                                      |
| 常用参数     | U, W                                  | h, w_t                                                   |
| 等压过程吸热 | $Q = \Delta U + p\Delta V = \Delta H$ | $q = \Delta h$                                           |

# 第3章 理想气体的性质

---

## 3.1 理想气体状态方程

### 三种形式（必背！）

| 形式             | 公式           | 说明                    |
| :--------------- | :------------- | :---------------------- |
| 基本形式（1kg）  | $pv = R_g T$   | 最常用，$R_g$是气体常数 |
| 质量m形式        | $pV = m R_g T$ | 质量为m时               |
| 摩尔形式（1mol） | $pV_m = RT$    | R是通用气体常数         |

### R 与 Rg 的关系（高频考点！）

$$\boxed{R_g = \frac{R}{M}}$$

$$\boxed{R = 8.314\ \text{J/(mol·K)}}$$

- R — **通用气体常数**，对所有理想气体相同
- Rg — **气体常数**，不同气体不同，取决于摩尔质量M
- 例：空气 M≈29 g/mol → $R_g = 8.314/0.029 ≈ 287\ \text{J/(kg·K)}$

---

## 3.2 理想气体的比热容

### 热容定义

$$C = \frac{\delta Q}{dT} \quad \text{或} \quad C = \lim_{\Delta T \to 0}\frac{Q}{\Delta T}$$

比热容 = 热容/质量：$c = C/m$

### 定压比热容 vs 定容比热容

$$\boxed{c_p = \left(\frac{\partial h}{\partial T}\right)_p}$$

$$\boxed{c_V = \left(\frac{\partial u}{\partial T}\right)_V}$$

### 迈耶公式（必背！）

$$\boxed{c_p - c_V = R_g}$$

### 比热容比（绝热指数）

$$\boxed{\kappa = \frac{c_p}{c_V}}$$

- 对理想气体，κ > 1（因为 $c_p > c_V$）
- 单原子气体 κ≈1.67
- 双原子气体 κ≈1.40
- 多原子气体 κ≈1.29

### 定值比热容表（需要默写！）

| 气体类型 | $c_V$            | $c_p$            | κ                    |
| :------- | :--------------- | :--------------- | :------------------- |
| 单原子   | $\frac{3}{2}R_g$ | $\frac{5}{2}R_g$ | $\frac{5}{3}$ ≈ 1.67 |
| 双原子   | $\frac{5}{2}R_g$ | $\frac{7}{2}R_g$ | $\frac{7}{5}$ = 1.40 |
| 多原子   | $\frac{7}{2}R_g$ | $\frac{9}{2}R_g$ | $\frac{9}{7}$ ≈ 1.29 |

> 记忆技巧：单原子 = 3（自由度）/ 双原子 = 5 / 多原子 = 7，除2乘Rg得$c_V$，再加Rg得$c_p$。

### 比热容与温度的关系

$$c_p = a + bT + cT^2 + dT^3$$

（考试中通常给表或给定值，不要求背系数）

---

## 3.3 理想气体的热力学能、焓、熵

### 焦耳定律

> **理想气体的热力学能只与温度有关**，与压力、比体积无关。

$$u = f(T) \quad \text{（仅对理想气体）}$$

### 热力学能变化

$$\boxed{\Delta u = u_2 - u_1 = \int_{T_1}^{T_2} c_V \, dT}$$

- 定值比热容时：$\Delta u = c_V (T_2 - T_1)$
- **适用条件**：理想气体，任意过程！

> ⚠️ 虽然$\Delta u = c_V \Delta T$中用了$c_V$，但这对**任何过程**都成立（不仅限于等容过程），因为理想气体的内能只与温度有关！

### 焓的类似性质

> **理想气体的焓也只与温度有关。**

$$\boxed{\Delta h = h_2 - h_1 = \int_{T_1}^{T_2} c_p \, dT}$$

- 定值比热容时：$\Delta h = c_p (T_2 - T_1)$
- **适用条件**：理想气体，任意过程！

### 熵

> **熵不能直接测量**，只能通过计算获得。
> **熵是状态参数**，熵变只与初终态有关。

### 熵的定义

$$ds = \frac{\delta q_{rev}}{T} \quad \text{（可逆过程）}$$

### 理想气体熵变的三个计算式（必背！）

$$\boxed{\Delta s = c_V \ln\frac{T_2}{T_1} + R_g \ln\frac{v_2}{v_1}}$$

$$\boxed{\Delta s = c_p \ln\frac{T_2}{T_1} - R_g \ln\frac{p_2}{p_1}}$$

$$\boxed{\Delta s = c_V \ln\frac{p_2}{p_1} + c_p \ln\frac{v_2}{v_1}}$$

> **记忆技巧**：三选二（T、p、v选两个），系数看前面的比热容类型。
> - 含T和v：用$c_V$ + $R_g$
> - 含T和p：用$c_p$ − $R_g$
> - 含p和v：用$c_V$ + $c_p$

---

## 3.4 理想气体混合物

### 成分表示

|      | 质量分数       | 摩尔分数       |
| :--- | :------------- | :------------- |
| 定义 | $w_i = m_i/m$  | $x_i = n_i/n$  |
| 关系 | $\sum w_i = 1$ | $\sum x_i = 1$ |

### 道尔顿分压定律

$$\boxed{p_i = x_i p}$$

- $p_i$：组分i的分压力
- $p$：混合气体的总压力
- 分压力 = 摩尔分数 × 总压力

### 分体积定律（阿马格定律）

$$V_i = x_i V$$

- 分体积 = 摩尔分数 × 总体积

### 混合气体的折合参数

| 参数         | 按质量分数               | 按摩尔分数          |
| :----------- | :----------------------- | :------------------ |
| 折合气体常数 | $R_g = \sum w_i R_{g,i}$ | $R_g = R / M_{mix}$ |
| 折合摩尔质量 | $M = 1/\sum(w_i/M_i)$    | $M = \sum x_i M_i$  |
| 折合比热容   | $c = \sum w_i c_i$       |                     |

# 第4章 理想气体的热力过程

---

## 📊 四大基本热力过程总览（核心！）

> 所有公式基于**理想气体、可逆过程、定值比热容**的前提。

| 过程               | 过程方程          | p-V关系                       | T-V关系                                        | T-p关系                                                      | Δu            | Δh            | W（膨胀功）              | Q             |
| :----------------- | :---------------- | :---------------------------- | :--------------------------------------------- | :----------------------------------------------------------- | :------------ | :------------ | :----------------------- | :------------ |
| **等容**           | v = const         | —                             | $\frac{T_2}{T_1}=\frac{p_2}{p_1}$              | —                                                            | $c_V\Delta T$ | $c_p\Delta T$ | 0                        | $c_V\Delta T$ |
| **等压**           | p = const         | —                             | $\frac{T_2}{T_1}=\frac{v_2}{v_1}$              | —                                                            | $c_V\Delta T$ | $c_p\Delta T$ | $p(v_2-v_1)=R_g\Delta T$ | $c_p\Delta T$ |
| **等温**           | T = const         | $p_1v_1=p_2v_2$               | —                                              | —                                                            | 0             | 0             | $R_gT\ln\frac{v_2}{v_1}$ | =W            |
| **等熵(可逆绝热)** | $pv^\kappa$=const | $p_1v_1^\kappa=p_2v_2^\kappa$ | $\frac{T_2}{T_1}=(\frac{v_1}{v_2})^{\kappa-1}$ | $\frac{T_2}{T_1}=(\frac{p_2}{p_1})^{\frac{\kappa-1}{\kappa}}$ | $c_V\Delta T$ | $c_p\Delta T$ | $-\Delta u$              | 0             |

### 可逆绝热（等熵）过程的三个等价形式

$$\boxed{pv^\kappa = const}$$

$$\boxed{Tv^{\kappa-1} = const}$$

$$\boxed{Tp^{\frac{1-\kappa}{\kappa}} = const}$$

> ⚠️ 适用条件：**理想气体 + 可逆绝热过程 + 定值比热容**

---

## 4.1 等容过程

- 过程方程：$v = const$
- 膨胀功：$W = 0$
- 热量：$Q = \Delta U = m c_V (T_2 - T_1)$
- **P-V图**：一条竖直线

---

## 4.2 等压过程

- 过程方程：$p = const$
- 膨胀功：$W = p(V_2 - V_1) = mR_g(T_2 - T_1)$
- 热量：$Q = \Delta H = m c_p (T_2 - T_1)$
- 举例：锅炉中的吸热过程近似等压
- **P-V图**：一条水平线

---

## 4.3 等温过程

- 过程方程：$pv = const$（即 $T = const$）
- Δu = 0，Δh = 0
- 膨胀功 = 技术功 = $mR_gT\ln\frac{v_2}{v_1} = mR_gT\ln\frac{p_1}{p_2}$

> ⚠️ **等温过程中膨胀功 = 技术功！** 因为 $pv = const$，$d(pv) = 0$。

---

## 4.4 可逆绝热过程（等熵过程）

- 过程方程：$pv^\kappa = const$
- Q = 0
- 膨胀功：$W = -\Delta U = m c_V (T_1 - T_2)$
- 技术功：$W_t = -\Delta H = m c_p (T_1 - T_2)$

> 技术功 = κ × 膨胀功：$w_t = \kappa w$

---

## 4.5 多变过程

### 多变过程方程

$$\boxed{pv^n = const}$$

- n：多变指数，可以取任意实数
- n = 0 → 等压；n = 1 → 等温；n = κ → 等熵；n = ±∞ → 等容

### 多变过程在P-V图和T-S图上的表示

| n值    | 过程类型 | P-V图斜率  | 说明         |
| :----- | :------- | :--------- | :----------- |
| n = 0  | 等压     | 水平线     | p = const    |
| n = 1  | 等温     | 双曲线     | pv = const   |
| n = κ  | 等熵     | 比等温更陡 | pv^κ = const |
| n = ±∞ | 等容     | 竖直线     | v = const    |

### 多变过程的功和热量

膨胀功：$w = \frac{R_g}{n-1}(T_1 - T_2) \quad (n \neq 1)$

技术功：$w_t = nw$

热量：$q = \Delta u + w = c_V(T_2-T_1) + \frac{R_g}{n-1}(T_1-T_2)$

## 4.6 气体的压缩

### 增压比

$$\pi = \frac{p_2}{p_1}$$

### 等温 vs 绝热压缩对比

|          | 等温压缩        | 绝热压缩 |
| :------- | :-------------- | :------- |
| 耗功     | 少              | 多       |
| 排气温度 | 低（=进气温度） | 高       |
| 压缩效率 | 高              | 低       |

> **结论**：等温压缩最省功！实际中尽量冷却以接近等温。

### 压气机效率

等温效率：$\eta_{c,T} = \frac{w_{T,s}}{w_{c,s}}$

绝热效率：$\eta_{c,s} = \frac{w_{c,s}}{w_{c,s}'}$（理想绝热耗功/实际绝热耗功）

### 余隙容积

- 余隙容积使有效吸气量减少
- **容积效率**：$\eta_V = 1 - c(\pi^{1/n} - 1)$
  - c：余隙容积比
  - π：增压比
- 余隙容积比c越大 → 容积效率越低
- 增压比π越大 → 容积效率越低

### 两级压缩中间冷却

**为什么要多级压缩？**
- 单级增压比过高 → 排气温度过高 → 润滑油碳化、爆炸危险
- 耗功大，容积效率低

**最佳中间压力**（耗功最少时）：

$$\boxed{p_m = \sqrt{p_1 p_2}}$$

即：$\frac{p_m}{p_1} = \frac{p_2}{p_m}$（各级增压比相等）

# 第5章 热力学第二定律与熵

---

## 5.1 热力学第二定律的两种表述

| 克劳修斯表述                                             | 开尔文-普朗克表述                                      |
| :------------------------------------------------------- | :----------------------------------------------------- |
| **热不可能自发地从低温物体传到高温物体而不引起其他变化** | **不可能从单一热源取热使之完全变为功而不产生其他变化** |
| 强调热传递的方向性                                       | 强调热功转换的方向性（第二类永动机不可能）             |

---

## 5.2 卡诺循环与卡诺定理

### 卡诺循环（两个等温+两个等熵）

**T-S图上的矩形**，是最简单的可逆循环。

$$\boxed{\eta_C = 1 - \frac{T_L}{T_H}}$$

- $T_H$：高温热源温度（K）
- $T_L$：低温热源温度（K）
- **卡诺循环的热效率只取决于两个热源的温度！**

### 如何提高热效率？

1. **提高高温热源温度** $T_H$ ↑
2. **降低低温热源温度** $T_L$ ↓
3. 但 $T_L$ 不能低于环境温度！（不能人为将低温热源降到环境温度以下，否则违背第二定律）

### 逆向卡诺循环

|          | 逆向卡诺循环                             |
| :------- | :--------------------------------------- |
| 制冷系数 | $\varepsilon_C = \frac{T_L}{T_H - T_L}$  |
| 热泵系数 | $\varepsilon'_C = \frac{T_H}{T_H - T_L}$ |
| 关系     | $\varepsilon'_C = \varepsilon_C + 1$     |

### 概括性卡诺循环

> 当吸热和放热不是等温过程，而是沿着某个温度范围进行时：

$$\eta_t = 1 - \frac{T_L}{T_H}$$

其中 $T_H$、$T_L$ 用**平均吸热温度**和**平均放热温度**代替。

### 卡诺定理（两条）

1. **在两个给定的热源之间工作的所有可逆热机，其热效率相等，与工质无关**
2. **在两个给定的热源之间工作的不可逆热机的热效率，必定小于可逆热机的热效率**

$$\eta_{irr} < \eta_{rev} = \eta_C$$

---

## 5.3 熵与克劳修斯不等式

### 克劳修斯不等式（核心！）

$$\boxed{\oint \frac{\delta Q}{T} \leq 0}$$

- **等号**：可逆循环
- **不等号**：不可逆循环
- **熵的单位**：J/K 或 kJ/K

### 熵的定义

$$dS = \left(\frac{\delta Q}{T}\right)_{rev}$$

$$\Delta S = S_2 - S_1 = \int_1^2 \frac{\delta Q_{rev}}{T}$$

> 虽然定义式用了可逆过程，但**熵是状态参数**，熵变只取决于初终态。

### 固体、液体熵变的计算

$$\Delta s = c \ln\frac{T_2}{T_1}$$

（固体和液体近似不可压缩，$c_p ≈ c_V ≈ c$）

### 闭口系熵方程

$$\boxed{\Delta S = S_f + S_g}$$

$$\boxed{S_f = \int_1^2 \frac{\delta Q}{T_r}}$$

- $S_f$（熵流）：由热交换引起的熵变，可正可负
- $S_g$（熵产）：由不可逆因素引起的熵变，**永不为负**！
- $T_r$：热源温度

### 等熵的两种情况

从 $\Delta s = c_p \ln\frac{T_2}{T_1} - R_g \ln\frac{p_2}{p_1} = 0$：

1. **可逆绝热过程**（ds = 0）
2. **不可逆过程（如摩擦生热刚好被向外传热抵消），但初终态熵值相同**（巧合）

> ⚠️ "等熵"不等于"可逆绝热"！可逆绝热一定是等熵的，但等熵不一定是可逆绝热。

### 平均吸热温度和平均放热温度

$$\bar{T}_H = \frac{Q_1}{\Delta S_{12}}$$

$$\bar{T}_L = \frac{Q_2}{\Delta S_{34}}$$

---

## 5.4 熵增原理与做功能力损失

### 孤立系熵增原理

$$\boxed{\Delta S_{iso} \geq 0}$$

- **等号**：可逆过程
- **大于号**：不可逆过程
- **孤立系统的熵永不会减少！**
- 这是判断过程方向的普适判据。

### 做功能力损失

$$\boxed{W_L = T_0 \cdot \Delta S_g}$$

$$\boxed{I = T_0 \cdot \Delta S_{iso}}$$

- $W_L$（或 I）：做功能力损失
- $T_0$：环境温度
- **适用条件**：任何不可逆过程

> **核心理解**：不可逆过程使熵增加，从而损失了做功能力。损失量 = 环境温度 × 熵产。

---

## 5.5 㶲分析方法

### 热流㶲

$$\boxed{E_{x,Q} = Q\left(1 - \frac{T_0}{T}\right)}$$

- 热量㶲 = 热量中最大可能转化为功的部分
- **热流㶲是过程量**（取决于热源温度T）
- 余下的 $Q·T_0/T$ 是无法利用的㷻（anergy）

### 焓㶲

$$\boxed{e_x = (h - h_0) - T_0(s - s_0)}$$

- **焓㶲是状态参数**（取决于工质状态与环境状态）
- 即工质在给定状态下，通过可逆方式变化到环境状态时能做的最大技术功

### 㶲 vs 㷻

|            | 㶲 (Exergy)            | 㷻 (Anergy)              |
| :--------- | :--------------------- | :----------------------- |
| 定义       | 能量中可转化为功的部分 | 能量中不可转化为功的部分 |
| 可逆过程   | 㶲不变                 | 㷻不变                   |
| 不可逆过程 | 㶲减少，变为㷻         | 㷻增加                   |

# 第6章 水蒸气（实际气体性质）

## 6.1 水的相变与相图

### 基本概念

| 术语               | 含义                                           |
| :----------------- | :--------------------------------------------- |
| **饱和温度** $t_s$ | 在一定压力下，水沸腾时的温度                   |
| **饱和压力** $p_s$ | 在一定温度下，水沸腾时的压力                   |
| **关系**           | $t_s$ 和 $p_s$ **一一对应**，$p_s$ ↑ → $t_s$ ↑ |
| **未饱和水**       | 温度低于同压下饱和温度的水                     |
| **饱和水**         | 温度等于同压下饱和温度的水（即将沸腾）         |
| **干饱和蒸汽**     | 全部蒸发完毕，不含液滴的蒸汽                   |
| **过热蒸汽**       | 温度高于同压下饱和温度的蒸汽                   |
| **湿蒸汽**         | 饱和水与干饱和蒸汽的混合物                     |

---

## 6.2 水的等压气化过程

### "一点两线三区五态"（必背框架！）

**一点**：**临界点** C
- 临界参数：$T_c = 647.3\ \text{K} = 374.15\ \text{°C}$, $p_c = 22.12\ \text{MPa}$
- 临界点以上：气液不分，为超临界流体

**两线**：
- 饱和水线（下界线）：x = 0
- 干饱和蒸汽线（上界线）：x = 1

**三区**：
- 未饱和水区（过冷区）
- 湿蒸汽区（两相区）
- 过热蒸汽区

**五态**：
1. 未饱和水（过冷水）
2. 饱和水
3. 湿蒸汽
4. 干饱和蒸汽
5. 过热蒸汽

### P-V图和T-S图上的变化规律

> 随压力升高：
> - 饱和温度升高
> - 气化潜热减小
> - 饱和水线与干饱和蒸汽线靠近
> - 在临界点处汇合

### 气化阶段

**三个阶段**（以等压加热为例）：

1. **预热阶段**（未饱和水→饱和水）：液体加热，$q_l = h' - h_0$（液体热）
2. **气化阶段**（饱和水→干饱和蒸汽）：**气化潜热** $r = h'' - h'$
3. **过热阶段**（干饱和蒸汽→过热蒸汽）：过热热 $q_{sup} = h - h''$

---

## 6.3 水蒸气的状态参数

### 干度

$$\boxed{x = \frac{m_{蒸汽}}{m_{蒸汽} + m_{水}}}$$

- x = 0：饱和水
- x = 1：干饱和蒸汽
- 0 < x < 1：湿蒸汽

### 湿蒸汽的参数计算

$$v = xv'' + (1-x)v' \approx xv''$$

$$h = xh'' + (1-x)h'$$

$$s = xs'' + (1-x)s'$$

> 注意：$v'$（饱和水比体积）通常远小于$v''$，所以 $v ≈ x v''$。

### 气化潜热

$$\boxed{r = h'' - h'}$$

---

## 6.4 水蒸气的焓熵图（h-s图）

### h-s图的基本结构

- 横轴：s（比熵）
- 纵轴：h（比焓）
- 饱和线呈钟形（或倒U形）
- 临界点C在最高处

### 绝热节流在h-s图上

- 绝热节流：水平线（$h_1 = h_2$）
- 节流后压力降低，温度变化取决于焦耳-汤姆逊系数
- 在湿蒸汽区节流可能使蒸汽变干

# 第7章 气体与蒸汽的流动

---

## 7.1 一维稳定流动的基本方程

### 连续性方程（质量守恒）

$$\boxed{\dot{m} = \rho c A = const}$$

$$\boxed{\frac{dA}{A} = \frac{dc_f}{c_f}(\text{Ma}^2-1)}$$

**微分形式**：

$$\frac{d\rho}{\rho} + \frac{dc_f}{c_f} + \frac{dA}{A} = 0$$

> **计算质量流量的截面如何选取？** 选取最小截面（喉部），因为那里达到临界状态！

### 能量方程

$$h_1 + \frac{c_{f1}^2}{2} = h_2 + \frac{c_{f2}^2}{2} = const$$

即：**总焓守恒** = 静焓 + 动能。

### 可逆绝热方程式

$$pv^\kappa = const$$

（与第4章可逆绝热过程完全相同！）

### 声速和马赫数

声速：$$\boxed{a = \sqrt{\kappa R_g T}}$$

马赫数：$$\boxed{\text{Ma} = \frac{c_f}{a}}$$

| Ma     | 流动类型 | 特点               |
| :----- | :------- | :----------------- |
| Ma < 1 | 亚声速   | 扰动可向上游传播   |
| Ma = 1 | 声速     | 临界状态           |
| Ma > 1 | 超声速   | 扰动不能向上游传播 |

---

## 7.2 促进流动改变的条件

### 几何条件（核心！）

> 管截面变化对流速的影响取决于**马赫数**：

| Ma范围           | 加速（喷管）    | 减速（扩压管）  |
| :--------------- | :-------------- | :-------------- |
| Ma < 1（亚声速） | 截面收缩 dA < 0 | 截面扩大 dA > 0 |
| Ma > 1（超声速） | 截面扩大 dA > 0 | 截面收缩 dA < 0 |

### 渐缩管

- **亚声速来流**：适合做喷管（加速）
- **超声速来流**：适合做扩压管（减速）
- **渐缩喷管最多加速到声速**（Ma=1），不能超过声速！

### 缩放管（拉瓦尔喷管）才能达到超声速

- 收缩段：亚声速加速到声速
- 喉部：Ma=1（临界）
- 扩张段：继续加速到超声速

---

## 7.3 等熵滞止参数

### 滞止状态

> 将气流等熵地减速到静止（$c_f = 0$）时的状态。

滞止焓：$$h_0 = h + \frac{c_f^2}{2}$$

滞止温度：$$T_0 = T + \frac{c_f^2}{2c_p}$$

滞止压力：$$\frac{p_0}{p} = \left(1 + \frac{\kappa-1}{2}\text{Ma}^2\right)^{\frac{\kappa}{\kappa-1}}$$

---

## 7.4 喷管的计算

### 临界压比

$$\boxed{\beta_c = \frac{p_{cr}}{p_0} = \left(\frac{2}{\kappa+1}\right)^{\frac{\kappa}{\kappa-1}}}$$

- 对双原子气体（κ≈1.4）：$\beta_c ≈ 0.528$
- 对过热蒸汽（κ≈1.3）：$\beta_c ≈ 0.546$

### 喷管选型（考试重点！）

| 背压 $p_b$ 条件        | 选用喷管类型               |
| :--------------------- | :------------------------- |
| $p_b/p_0 \geq \beta_c$ | **渐缩喷管**               |
| $p_b/p_0 < \beta_c$    | **缩放喷管**（拉瓦尔喷管） |

> ⚠️ **渐缩喷管不能产生超声速流！** 出口最多达到声速（Ma=1）。

### 渐缩喷管的质量流量

当 $p_b/p_0 > \beta_c$ 时，$p_{出口} = p_b$（流量随$p_b$降低而增加）

当 $p_b/p_0 \leq \beta_c$ 时，$p_{出口} = p_{cr}$（流量不再增加，达到最大值 — **壅塞**）

### 喷管出口流速

$$c_{f2} = \varphi \sqrt{2(h_1 - h_{2s})}$$

- φ：速度系数（0 < φ ≤ 1），衡量摩擦损失
- $h_{2s}$：等熵膨胀到出口压力时的焓

---

## 7.5 有摩擦阻力的绝热流动

- 实际流动中摩擦使熵增加
- 出口实际焓 > 等熵情况下的出口焓
- 出口实际流速 < 等熵情况下的出口流速
- 可以用**速度系数** φ 或**效率**来修正

---

## 7.6 绝热节流（第2章已有，此处深化）

### 绝热节流系数（焦耳-汤姆逊系数）

$$\boxed{\mu_J = \left(\frac{\partial T}{\partial p}\right)_h}$$

| $\mu_J$     | 含义                       |
| :---------- | :------------------------- |
| $\mu_J > 0$ | 节流后温度降低（冷效应）   |
| $\mu_J = 0$ | 节流后温度不变（理想气体） |
| $\mu_J < 0$ | 节流后温度升高（热效应）   |

> 对理想气体：$\mu_J = 0$（T不变）
> 对实际气体：大多数情况下 $\mu_J > 0$（节流降温，常用于制冷）

# 第8章 蒸汽动力装置循环

---

## 8.1 朗肯循环（Rankine Cycle）

### 四大部件

| 部件       | 过程            | T-S图              |
| :--------- | :-------------- | :----------------- |
| **锅炉**   | 等压加热（4→1） | 水→过热蒸汽        |
| **汽轮机** | 等熵膨胀（1→2） | 做功，进入湿蒸汽区 |
| **凝汽器** | 等压放热（2→3） | 蒸汽→饱和水        |
| **给水泵** | 等熵压缩（3→4） | 水加压             |

### 朗肯循环的T-S图分析

- 1→2：等熵膨胀（汽轮机做功，$w_T = h_1 - h_2$）
- 2→3：等压冷凝（放热，$q_2 = h_2 - h_3$）
- 3→4：等熵压缩（泵耗功，$w_P = h_4 - h_3$）
- 4→1：等压加热（吸热，$q_1 = h_1 - h_4$）

### 朗肯循环热效率

$$\boxed{\eta_t = \frac{w_{net}}{q_1} = \frac{(h_1-h_2) - (h_4-h_3)}{h_1 - h_4}}$$

当忽略泵功时（泵功很小）：

$$\eta_t \approx \frac{h_1 - h_2}{h_1 - h_3}$$

### 汽耗率、热耗率、煤耗率

| 指标         | 定义                       | 公式                              |
| :----------- | :------------------------- | :-------------------------------- |
| **汽耗率** d | 每产生1kWh功所消耗的蒸汽量 | $d = \frac{3600}{w_{net}}$ kg/kWh |
| **热耗率** q | 每产生1kWh功所消耗的热量   | $q = d \cdot q_1$ kJ/kWh          |
| **煤耗率** b | 每产生1kWh功所消耗的煤量   | $b = q / Q_{net}$ kg/kWh          |

### 汽轮机相对内效率

$$\boxed{\eta_{ri} = \frac{h_1 - h_2}{h_1 - h_{2s}}}$$

- $h_1 - h_2$：实际焓降
- $h_1 - h_{2s}$：等熵焓降（理想焓降）

### 如何提高朗肯循环热效率？

| 措施                 | 原理                       | 限制                       |
| :------------------- | :------------------------- | :------------------------- |
| **提高初温** $T_1$ ↑ | 提高平均吸热温度           | 受材料耐热限制（~620°C）   |
| **提高初压** $p_1$ ↑ | 提高平均吸热温度           | 终态湿度增大（对叶片不利） |
| **降低背压** $p_2$ ↓ | 降低平均放热温度           | 受环境温度限制             |
| **再热循环**         | 提高初参数同时控制终态湿度 | 系统复杂                   |
| **回热循环**         | 利用抽汽加热给水           | 设备增加                   |

---

## 8.2 再热循环（Reheat Cycle）

### 工作原理

1. 高压缸膨胀到中间压力
2. 回到锅炉再热到初温
3. 低压缸继续膨胀到背压

### 优点

- 提高终态干度（减少湿蒸汽对叶片的侵蚀）
- 可同时提高初压和初温，进一步提高效率

### 热效率

$$\eta_t = \frac{(h_1 - h_a) + (h_b - h_2) - w_P}{(h_1 - h_4) + (h_b - h_a)}$$

---

## 8.3 抽汽回热循环（Regenerative Cycle）

### 工作原理

- 从汽轮机中间级抽取部分蒸汽
- 用抽汽在回热加热器中加热给水
- 提高给水温度 → 提高平均吸热温度

### 优点

- 提高热效率（接近卡诺循环效率）
- 抽汽级数越多，效率越接近极限

### 回热循环T-S图

- 循环内部出现"锯齿"
- 平均吸热温度明显提高

---

## 8.4 热电联产循环

### 定义

> 同时供电和供热的循环，实现能量的**梯级利用**。

### 类型

1. **背压式**：汽轮机排汽压力高于大气压，排汽直接用于供热
2. **抽汽式**：从汽轮机中间抽汽用于供热

### 评价指标

$$\eta_{cogen} = \frac{W + Q_h}{Q_{fuel}}$$

- W：发电量
- Q_h：供热量
- 总效率可超过80%

---

## 📊 各循环对比总结

| 循环类型 | T-S图形状   | 热效率                                 | 特点                        |
| :------- | :---------- | :------------------------------------- | :-------------------------- |
| 卡诺循环 | 矩形        | 最高（理论极限）                       | 等温吸热+等温放热，不可实现 |
| 朗肯循环 | 近似矩形    | $\eta \approx \frac{h_1-h_2}{h_1-h_3}$ | 实际可行的基本循环          |
| 再热循环 | 基本+附加环 | 略高于朗肯                             | 克服湿度问题                |
| 回热循环 | 内部锯齿    | 明显高于朗肯                           | 提高平均吸热温度            |
| 热电联产 | —           | 总效率>80%                             | 能量梯级利用                |

# 📝 附录：常见考试陷阱提醒

1. **表压力不是状态参数**（第1章），计算必须用**绝对压力**
2. **平衡 ≠ 稳定**（第1章），平衡一定有稳定，稳定不一定平衡
3. **可逆过程一定是准静态的，反过来不一定**（第1章）
4. **焓是状态参数**（第2章），不管什么过程都可以用$\Delta h = c_p\Delta T$（理想气体）
5. **热力学能是状态参数**（第2章），不管什么过程都可以用$\Delta u = c_V\Delta T$（理想气体）
6. **绝热节流是等焓但不是等温**（对实际气体）（第2,7章）
7. **等熵 ≠ 可逆绝热**（第5章），等熵也可能是巧合
8. **$c_p - c_V = R_g$ 只对理想气体成立**（第3章），不适用于实际气体
9. **渐缩喷管最多产生声速流动**（第7章），超声速必须有缩放喷管
10. **朗肯循环效率公式中泵功常可忽略**（第8章），但概念上不能忘记
